Place GPX files here.

File naming:
- Use mountain name tokens, e.g. mt_apo.gpx, talungan_trail_site.gpx.
- The app auto-matches mountain name to GPX filename.

GPX expectations:
- Track points: <trkpt lat="..." lon="...">...</trkpt>
- Optional waypoints for checkpoints: <wpt ...><name>Camp 1</name></wpt>
- Optional summit waypoint names containing "Peak" or "Summit".
